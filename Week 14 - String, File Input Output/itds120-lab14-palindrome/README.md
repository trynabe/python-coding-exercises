# Check Palindrome String

จงเขียนโปรแกรมที่สามารถตรวจสอบได้ว่าข้อความที่ผู้ใช้ป้อนเป็น **Palindrome** หรือไม่  

ข้อความที่เป็น Palindrom คือข้อความที่อ่านจากซ้ายไปขวาและขวาไปซ้ายแล้วเหมือนกัน

ให้ละเว้นการพิจารณาตัวพิมพ์เล็ก–ใหญ่ และไม่สนใจเว้นวรรค และสัญลักษณ์พิเศษ

**ตัวอย่างข้อความ**  
```

Madam

```
โปรแกรมจะแสดงผลว่า  
```

palindrome

```

<hr>

**ตัวอย่างที่ 1:**  
**Input:**  
```

ra , ce <ca> R

```
**Expected output:**  
```

palindrome

```

<hr>

**ตัวอย่างที่ 2:**  
**Input:**  
```

Hel>>lo

```
**Expected output:**  
```

not palindrome

```
